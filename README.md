# Анализ дефектов строительных работ

Автоматический анализ PDF-документов с экспертизами строительных работ. Извлекает текст, находит дефекты через AI и создает Excel отчет.

## Два режима работы

### 1. Telegram бот (main.py)
Интерактивная обработка документов через Telegram

### 2. Batch обработка (batch_runner.py)
Автоматическая пакетная обработка всех PDF из папки

---

## Быстрый старт

### Установка

1. **Клонируйте репозиторий и перейдите в директорию:**
```bash
cd osmi_demo_1-1
```

2. **Установите зависимости:**
```bash
pip install -r requirements.txt
```

3. **Настройте переменные окружения:**
```bash
# Скопируйте шаблон
cp .env.example .env

# Отредактируйте .env и добавьте токены:
# BOT_TOKEN=ваш_токен_от_BotFather
# OPENAI_API_KEY=ваш_ключ_openai
```

---

## Запуск

### Вариант 1: Telegram бот

```bash
python main.py
```

**Использование:**
1. Откройте бота в Telegram
2. Отправьте `/start`
3. Нажмите "Загрузить документ"
4. Отправьте ссылку на PDF из Google Drive
5. Получите Excel отчет (~7-9 минут)

---

### Вариант 2: Batch обработка

```bash
python batch_runner.py
```

**Как работает:**
- Сканирует папку `data/input/` и обрабатывает все PDF
- Пропускает уже обработанные файлы
- Результаты сохраняет в `result/<timestamp>/`
- Выводит статистику по каждому файлу

---

### Вариант 3: Тестирование одного файла

Для отладки и тестирования отдельного документа:

```bash
python run_pipeline.py
```

**Что нужно:**
- Отредактируйте `run_pipeline.py`
- Укажите путь к тестовому PDF файлу
- Запустите скрипт

---

## Этапы обработки

Каждый документ проходит через 4 этапа:

1. **OCR** (~4-5 мин) — распознавание текста из PDF
2. **Semantic Filter** (~30 сек) — отбор страниц с дефектами
3. **VLM Cleaning** (~1-2 мин) — очистка текста через GPT Vision
4. **Analysis** (~1 мин) — извлечение дефектов и создание Excel

**Итого:** ~7-9 минут на один документ

---

## Результаты

После обработки вы получите:

**Excel файл с таблицей дефектов:**
- Текст из экспертизы
- Помещение
- Локализация
- Описание дефекта
- Тип работ для устранения

**Дополнительные файлы (в папке result/):**
- `full_text_*.txt` — полный распознанный текст
- `full_text_cleaned.json` — очищенный текст со страниц

## Конфигурация

**Все настройки находятся в `config.py`:**

```python
# Порог отбора страниц (0.0-1.0, чем выше — тем строже)
SEMANTIC_SCORE_THRESHOLD = 0.5

# Максимальное количество страниц для анализа
SEMANTIC_TOP_PAGES_LIMIT = 10

# Модель для Vision LLM (очистка текста)
VLM_MODEL = "gpt-4.1-mini"

# Модель для анализа дефектов
ANALYSIS_MODEL = "gpt-4.1-2025-04-14"
```

**Переменные окружения (в `.env`):**
- `BOT_TOKEN` — токен Telegram бота
- `OPENAI_API_KEY` — ключ OpenAI API
